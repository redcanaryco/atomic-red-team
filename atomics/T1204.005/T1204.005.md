# T1204.005 - User Execution: Malicious Library

## Description from ATT&CK

> Adversaries may rely on a user installing a malicious library to facilitate execution. Threat actors may [Upload Malware](https://attack.mitre.org/techniques/T1608/001) to package managers such as NPM and PyPi, as well as to public code repositories such as GitHub. User may install libraries without realizing they are malicious, thus bypassing techniques that specifically achieve Initial Access. This can lead to the execution of malicious code, such as code that establishes persistence, steals data, or mines cryptocurrency.(Citation: Datadog Security Labs Malicious PyPi Packages 2024)(Citation: Fortinet Malicious NPM Packages 2023)
> 
> In some cases, threat actors may compromise and backdoor existing popular libraries (i.e., [Compromise Software Dependencies and Development Tools](https://attack.mitre.org/techniques/T1195/001)). Alternatively, they may create entirely new packages and leverage behaviors such as typosquatting to encourage users to install them.

### Atomic Test #1: Execute a synthetic npm package postinstall script

Simulates user execution of a malicious library by installing a local, synthetic npm package whose
`postinstall` lifecycle script executes JavaScript and creates a harmless marker file. This behavior
represents the package-install execution pattern associated with malicious npm packages and campaigns
such as the DPRK-linked Contagious Interview activity.

The test does not contact an npm registry, download code, collect credentials, establish persistence,
or execute an operator-supplied payload. Expected output includes npm reporting execution of the
package's `postinstall` script, creation of the T1204.005 marker file, and a success message containing
the marker contents.

#### Attack Commands: Run with `powershell`!

```powershell
$ErrorActionPreference = 'Stop'
$npmPath = [Environment]::ExpandEnvironmentVariables("#{npm_path}")
$packagePath = [Environment]::ExpandEnvironmentVariables("#{package_path}")
$workingDirectory = [Environment]::ExpandEnvironmentVariables("#{working_directory}")
$markerPath = [Environment]::ExpandEnvironmentVariables("#{marker_path}")

if (Test-Path -LiteralPath $workingDirectory) {
  throw "Refusing to use pre-existing working directory: $workingDirectory"
}

New-Item -ItemType Directory -Path $workingDirectory -Force | Out-Null
$env:ART_T1204_005_MARKER = $markerPath

try {
  $npmArguments = @(
    'install'
    $packagePath
    '--prefix', $workingDirectory
    '--cache', (Join-Path $workingDirectory '.npm-cache')
    '--no-audit'
    '--no-fund'
    '--ignore-scripts=false'
    '--foreground-scripts'
  )

  & $npmPath @npmArguments
  $npmExitCode = $LASTEXITCODE

  if ($npmExitCode -ne 0) {
    throw "npm install failed with exit code $npmExitCode"
  }

  if (-not (Test-Path -LiteralPath $markerPath -PathType Leaf)) {
    throw "npm completed without creating the expected marker: $markerPath"
  }

  $markerContent = Get-Content -LiteralPath $markerPath -Raw
  if ($markerContent -notmatch 'Atomic Red Team T1204\.005') {
    throw 'The marker file did not contain the expected Atomic Red Team identifier.'
  }

  Write-Host 'T1204.005 synthetic npm postinstall execution succeeded.'
  Write-Output $markerContent.Trim()
}
finally {
  Remove-Item Env:\ART_T1204_005_MARKER -ErrorAction SilentlyContinue
}
```
