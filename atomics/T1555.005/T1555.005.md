# T1555.005 - Password Managers

## Description from ATT&CK

> Adversaries may search for common password manager databases (such as KeePass, 1Password, Bitwarden, and LastPass) or configuration files on local and network drives. Password managers store encrypted credentials, notes, and keys within database files (e.g., `.kdbx` for KeePass). If an adversary obtains access to the database file or the configuration that references it, they may attempt offline brute-force attacks, extract cached master keys from process memory, or exfiltrate the database for cryptanalysis.

[Source](https://attack.mitre.org/techniques/T1555/005)

## Atomic Test #1 - KeePass Database File (.kdbx / .kdb) Discovery via PowerShell

Adversaries search filesystem directories (such as user profiles, desktop, documents, and temp folders) for KeePass database files (.kdbx, .kdb) which store encrypted credentials and master databases.
This test simulates the discovery technique by creating a test database file with KeePass header magic bytes, scanning common directories, and outputting discovered database metadata.

**Supported Platforms:** Windows

**auto_generated_guid:** `9d1e3cba-8e4f-4d54-b89b-b705644335b9`

#### Inputs:
| Name | Description | Type | Default Value |
|------|-------------|------|---------------|
| search_path | Root folder to search for KeePass databases | path | $env:USERPROFILE |
| test_db_path | Path to create a simulated KeePass database file | path | $env:TEMP\AtomicTest_Vault.kdbx |

#### Attack Commands: Run with `powershell`!

```powershell
if (-not (Test-Path "#{test_db_path}")) {
  [IO.File]::WriteAllBytes("#{test_db_path}", [byte[]](0x03, 0xD9, 0xA2, 0x9A, 0x67, 0xFB, 0x4B, 0xB5))
}
Write-Host "Searching for KeePass databases in #{search_path} and temp..."
Get-ChildItem -Path "#{search_path}", $env:TEMP -Include *.kdbx, *.kdb -Recurse -File -ErrorAction SilentlyContinue | Select-Object FullName, Length, LastWriteTime
```

#### Cleanup Commands:

```powershell
Remove-Item -Path "#{test_db_path}" -Force -ErrorAction Ignore
```

## Atomic Test #3 - KeePass Configuration and Recent Databases Discovery (KeePass.config.xml)

KeePass stores recent database file paths, user preferences, and trigger configurations in KeePass.config.xml.
Adversaries inspect this configuration file to locate active database paths or identify trigger execution opportunities.
This test creates a simulated KeePass.config.xml, reads it to parse the last used database path, and cleans up after execution.

**Supported Platforms:** Windows

**auto_generated_guid:** `12e255b1-1c9a-47dd-bbab-7f0c1a8e7ea0`

#### Inputs:
| Name | Description | Type | Default Value |
|------|-------------|------|---------------|
| test_config_path | Path to create a simulated KeePass configuration XML file (use a test sandbox, never a real KeePass config) | path | $env:TEMP\AtomicTest_T1555_005\KeePass.config.xml |
| mock_db_path | Database path referenced in simulated configuration | path | C:\Users\Public\Documents\Company_Vault.kdbx |

#### Attack Commands: Run with `powershell`!

```powershell
$testConfigPath = "#{test_config_path}"
if ((Test-Path $testConfigPath) -and ((Get-Content -Path $testConfigPath -Raw) -notmatch 'AtomicTest T1555\.005')) {
  throw "Refusing to overwrite non-simulated KeePass config at $testConfigPath"
}
$configDir = Split-Path $testConfigPath
if (-not (Test-Path $configDir)) { New-Item -ItemType Directory -Path $configDir -Force | Out-Null }
$mockConfig = @"
<?xml version="1.0" encoding="utf-8"?>
<!-- AtomicTest T1555.005 simulated configuration -->
<Configuration>
  <Application>
    <LastUsedFile>
      <Path>#{mock_db_path}</Path>
    </LastUsedFile>
  </Application>
</Configuration>
"@
Set-Content -Path $testConfigPath -Value $mockConfig -Force
Write-Host "Inspecting simulated KeePass configuration file at ${testConfigPath}:"
[xml]$xml = Get-Content -Path $testConfigPath
$discoveredDb = $xml.Configuration.Application.LastUsedFile.Path
Write-Host "Discovered last used KeePass database: $discoveredDb"
```

#### Cleanup Commands:

```powershell
$testConfigPath = "#{test_config_path}"
if ((Test-Path $testConfigPath) -and ((Get-Content -Path $testConfigPath -Raw) -match 'AtomicTest T1555\.005')) {
  Remove-Item -Path $testConfigPath -Force -ErrorAction Ignore
}
```

## Atomic Test #4 - Staging Discovered KeePass Databases for Exfiltration

Simulates adversary behavior where discovered KeePass password vaults are copied to a staging directory and compressed into a zip archive prior to exfiltration.

**Supported Platforms:** Windows

**auto_generated_guid:** `0b4e0ef1-9c58-426d-ac17-19e718956c22`

#### Inputs:
| Name | Description | Type | Default Value |
|------|-------------|------|---------------|
| source_db | Path to simulated KeePass database file to be staged | path | $env:TEMP\AtomicTest_Target.kdbx |
| staging_dir | Temporary directory used to stage collected password vaults | path | $env:PUBLIC\T1555_005_Staging |
| archive_file | Destination zip archive file path | path | $env:PUBLIC\T1555_005_Vaults.zip |

#### Attack Commands: Run with `powershell`!

```powershell
if (-not (Test-Path "#{source_db}")) {
  [IO.File]::WriteAllBytes("#{source_db}", [byte[]](0x03, 0xD9, 0xA2, 0x9A, 0x67, 0xFB, 0x4B, 0xB5))
}
if (-not (Test-Path "#{staging_dir}")) {
  New-Item -ItemType Directory -Path "#{staging_dir}" -Force | Out-Null
}
Copy-Item -Path "#{source_db}" -Destination "#{staging_dir}\" -Force
Write-Host "Staging databases to #{staging_dir}:"
Get-ChildItem -Path "#{staging_dir}"
if (Test-Path "#{archive_file}") { Remove-Item -Path "#{archive_file}" -Force }
Add-Type -Assembly System.IO.Compression.FileSystem
[IO.Compression.ZipFile]::CreateFromDirectory("#{staging_dir}", "#{archive_file}")
Write-Host "Created archive at #{archive_file}: $((Get-Item '#{archive_file}').Length) bytes"
```

#### Cleanup Commands:

```powershell
Remove-Item -Path "#{source_db}" -Force -ErrorAction Ignore
Remove-Item -Path "#{staging_dir}" -Recurse -Force -ErrorAction Ignore
Remove-Item -Path "#{archive_file}" -Force -ErrorAction Ignore
```

Adversaries locate .kdbx and .kdb password manager databases on Linux systems by scanning common user directories and temporary paths.

**Supported Platforms:** Linux

**auto_generated_guid:** `c6d6d37e-c0d8-44fc-9109-7116dc8d7b22`

#### Inputs:
| Name | Description | Type | Default Value |
|------|-------------|------|---------------|
| test_dir | Path to temporary directory simulating user database folder | path | /tmp/atomic_t1555_005 |

#### Attack Commands: Run with `sh`!

```sh
mkdir -p "#{test_dir}" && touch "#{test_dir}/passwords.kdbx"
echo "Searching for KeePass databases in #{test_dir}..."

```
